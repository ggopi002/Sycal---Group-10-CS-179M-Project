# data/syllabi

Raw syllabus PDFs / HTML. Owner: Rehan.

Every file must have a row in `manifest.csv`:

```csv
file,course,term_start,term_end
cs179m.pdf,CS 179M,2026-09-24,2026-12-11
```

`term_end` should include finals week so final exams fall inside the term.

`sample.html` is a made-up syllabus for smoke tests; don't count it in experiment results.

**Privacy**: ask the classmate before using their syllabus, and remove anything personal
(student names, grades, private Zoom links) before committing. Instructor names and emails
printed on a syllabus are fine to keep.
